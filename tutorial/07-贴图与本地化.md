# 第 7 章：贴图与本地化

> 本章目标：给 mod 配上图标，并让它中英双语都能看。
> 打开对照：`Textures/PMM/`、`Languages/`、`tools/generate_textures.ps1`

## 7.1 贴图：路径规则是铁律

贴图放在 `Textures/` 下，代码/XML 里引用时**去掉 `Textures/` 前缀、去掉 `.png` 扩展名**：

| 文件实际位置 | 引用写法 |
|---|---|
| `Textures/PMM/UI/RemoveThickRoof.png` | `PMM/UI/RemoveThickRoof` |
| `Textures/PMM/Designations/RemoveThickRoof.png` | `PMM/Designations/RemoveThickRoof` |

本项目用到两处：

- **设计器按钮图标**（C# 里）：`ContentFinder<Texture2D>.Get("PMM/UI/RemoveThickRoof", true)`
  第二个参数 `true` = 找不到就报错（方便发现路径写错）；改成 `false` 则找不到就留空白、不报错。
- **指派标记图案**（XML 里）：`<texturePath>PMM/Designations/RemoveThickRoof</texturePath>`

> 贴图不显示？99% 是路径写错——对照上表检查"是否多写了 `Textures/` 或 `.png`"。

## 7.2 没有美术素材怎么办？程序化生成

新手常卡在"不会画图"。本项目的两张图标是用 `tools/generate_textures.ps1` 这个 PowerShell 脚本**代码画出来的**（灰山 + 红叉 = "移除山"），完全不依赖外部素材。

- 想重新生成/改图案：编辑该脚本后运行
  `powershell -NoProfile -ExecutionPolicy Bypass -File tools\generate_textures.ps1`
- 测试阶段**也可以直接借用原版贴图路径**（比如按钮图标先用 `UI/Designators/Mine`），正规化时再换原创图。

> ⚠️ 版权提醒：**可以**引用原版贴图路径；**不要**把原版/别的 mod 的贴图文件复制进自己的 mod 发布。正式发布的图标最好是自己画的。

## 7.3 本地化：Keyed 与 DefInjected 两种翻译

RimWorld 的翻译文件放 `Languages/<语言>/` 下。语言目录名：`English`、`ChineseSimplified`（简中）等。
翻译分**两种**，别搞混：

### ① Keyed —— 翻译"代码里的字符串"

C# 里写 `"PMM_某个键".Translate()`，运行时按当前语言查表。存放在 `Languages/<语言>/Keyed/`：

```xml
<!-- Languages/English/Keyed/PMM_Keys.xml -->
<LanguageData>
  <PMM_Designator_RemoveThickRoof_Label>Remove thick roof</PMM_Designator_RemoveThickRoof_Label>
</LanguageData>

<!-- Languages/ChineseSimplified/Keyed/PMM_Keys.xml -->
<LanguageData>
  <PMM_Designator_RemoveThickRoof_Label>移除厚岩顶</PMM_Designator_RemoveThickRoof_Label>
</LanguageData>
```

- **标签名 = 代码里的键**（`"PMM_Designator_RemoveThickRoof_Label".Translate()`）。
- **必须提供 English 版本作为兜底**：某语言缺了某键时，游戏会回退到英文。缺了英文兜底就可能直接显示原始键名。

### ② DefInjected —— 翻译"Def 里的字段"

Def 里的 `<label>`、`<reportString>` 等，用 DefInjected 翻译，存放在 `Languages/<语言>/DefInjected/<Def类型>/`。
**标签名规则是 `defName.字段名`**：

```xml
<!-- Languages/ChineseSimplified/DefInjected/JobDef/PMM_Jobs.xml -->
<LanguageData>
  <PMM_RemoveThickRoofJob.reportString>正在移除厚岩顶。</PMM_RemoveThickRoofJob.reportString>
</LanguageData>

<!-- Languages/ChineseSimplified/DefInjected/WorkGiverDef/PMM_WorkGivers.xml -->
<LanguageData>
  <PMM_RemoveThickRoof.label>移除厚岩顶</PMM_RemoveThickRoof.label>
  <PMM_RemoveThickRoof.verb>移除厚岩顶</PMM_RemoveThickRoof.verb>
  <PMM_RemoveThickRoof.gerund>移除厚岩顶</PMM_RemoveThickRoof.gerund>
</LanguageData>
```

- Def 文件本身写**英文**（作为默认），中文走 DefInjected 覆盖。
- `DefInjected` 下的子文件夹名要对应 Def 类型（`JobDef`、`WorkGiverDef`…）。

### 一句话区分

| 要翻译的东西 | 用哪种 | 放哪 |
|---|---|---|
| C# 里 `.Translate()` 的字符串 | Keyed | `Languages/<语言>/Keyed/` |
| Def 里的 `label`/`description`/`reportString` 等字段 | DefInjected | `Languages/<语言>/DefInjected/<Def类型>/` |

## 动手练

1. 把简中 Keyed 里的"移除厚岩顶"改成"开山"，重载语言看按钮名变了没。
2. 给 `PMM_Message_RoofRemoved` 这个键补一个你自己的中文提示，开启设置里的"完成提示"后凿掉一格看看。

## 本章小结

- 贴图引用路径 = 去掉 `Textures/` 和 `.png`；不显示先查路径。
- 没素材可程序化生成，或测试期借原版贴图路径。
- 代码字符串用 Keyed，Def 字段用 DefInjected；**英文做兜底**。
